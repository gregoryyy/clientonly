# Generated code for diverse client-only applications

This is a prototyping monorepo project for browser-only applications.

Code is created using:

- My ideas
- ChatGPT / Codex solutions (see GPT link in subdirs)
- Refinements manually and API help using Codex

# Overview

- gpt: LLM using WebLLM, showcasing GPU and proxy-based loading of models
- net: Network browser for large graphs

# Run

- Run via `python -m http.server 8080` from here or in the respective subdir.
